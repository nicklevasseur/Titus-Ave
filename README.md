# ZBA2026-063 — 26 Titus Avenue, Manchester NH

Opposition materials for a 13-unit multifamily variance application (Case #ZBA2026-063)
before the City of Manchester Zoning Board of Adjustment. Hearing: **Thursday,
September 10, 2026, 6:00 PM, City Hall, 3rd Floor Aldermanic Chambers.**

Prepared by Nick Levasseur, 30 Mystic Street, Manchester, NH 03103 (Ward 9).

## The project

T&L 2018, LLC proposes two townhouse buildings (8 units + 5 units = 13 multifamily
units) at 26 Titus Avenue (Map 554, Lot 17C), a 49,484 SF lot in the R-1B
(Residential One-Family, High Density) district. The application originally
sought relief from **nine** ordinance sections; three (dumpster location,
parking-drive landscaping, fence height) were resolved in a subsequent plan
revision and confirmed by Planning & Community Development as no longer being
pursued. **Six** sections remain live as of the September 10, 2026 hearing.

## Regenerating documents

Each document in `documents/` is generated by a corresponding script in
`scripts/`, using the [`docx`](https://www.npmjs.com/package/docx) npm
package. To regenerate any or all of them:

```bash
cd scripts
npm install
npm run build        # regenerates all six .docx files into ../documents
# or individually:
npm run handout
npm run criteria
npm run testimony
npm run memo
npm run fieldref
npm run comparison
```

Each script writes a `.docx` file directly into `documents/`. To get a PDF,
open the `.docx` in Word/LibreOffice and export, or convert with a tool like
`libreoffice --headless --convert-to pdf`.

`assets/` holds the two images used in the handout (the developer's own
building elevation rendering and the site plan aerial, both cropped from the
official application packet).

## Key legal citations

The five statutory variance criteria are RSA 674:33, I(a)(2)(A)–(E); the
"unnecessary hardship" definition is I(b)(1)–(3). Case law used throughout
(all independently verified against primary/authoritative sources):

- *Simplex Technologies, Inc. v. Town of Newington*, 145 N.H. 727 (2001)
- *Olszak v. Town of New Hampton*, 139 N.H. 723, 726 (1995)
- *Governor's Island Club v. Town of Gilford*, 124 N.H. 126, 130 (1983)
- *Ryan v. City of Manchester*, 123 N.H. 170, 174 (1983)
- *Chester Rod & Gun Club v. Town of Chester*, 152 N.H. 577, 581 (2005)
- *Harborside Assocs. v. Parade Residence Hotel*, 162 N.H. 508, 514 (2011)
- *Malachy Glen Assocs. v. Town of Chichester*, 155 N.H. 102 (2007)
- *Boccia v. City of Portsmouth*, 151 N.H. 85 (2004)
- *Bacon v. Town of Enfield* (2004) — "cumulative effect," referenced but never
  formally adopted by the NH Supreme Court; flagged as lower-confidence
  wherever it's cited

Full citation-by-citation detail is in the Board Memo and Field Reference
appendices.
